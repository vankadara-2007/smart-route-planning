    Understanding the Algorithms

    BFS

    Explores nodes level by level. Finds a path with the fewest edges in an unweighted graph.

    DFS

    Explores one branch deeply before backtracking. Does not guarantee the lowest cost.

    UCS

    Expands the lowest accumulated cost first. Finds a minimum-cost route with non-negative edges.

    Greedy Best-First

    Uses a heuristic to move toward the destination. It does not guarantee the lowest cost.

    A* Search

    Uses path cost plus heuristic: f(n) = g(n) + h(n). An admissible heuristic ensures optimality under standard conditions.
